# Lab 4 规格与本人参与

这些 YAML 是本项目按课程 PPT 起草的设计，不是课程仓库提供的原件。当前平台为 QEMU，实体开发板配置暂缓。

先读 `design.yaml` 的目标和地址布局，再读 `patches/lab4.yaml` 的验收场景；各模块的 `functions` 规定调用前条件、作用和完成后的状态。规格在源码实现前真实提交，之后再提交实现与证据。

本轮按你“先把实验做完”的安排，由 Agent 起草规格并实现，不把草稿记成本人独立设计。你可以从三个函数参与：`user_vm_create` 说明允许访问哪些页、失败时谁回收；`process_run` 说明 PCB 记住哪些资源；`trap_user_return` 说明如何由内核回到用户。个人解释和真实运行结果由你填写到本阶段 `docs/NOTES.md`，有内容时再创建。
